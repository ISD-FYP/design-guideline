# Dog Diary Design Guideline

Design system documentation for **Dog Diary** — HKUST ISDN 4001 Final Year Project, Group 7.

- `DESIGN.md` — design tokens and rules: palette (paper `FAF7F1`, terracotta `C05B2E`, sage `7E8C6D`, espresso ink `2D251E`), Fraunces + Avenir Next type pairing, layout grid, imagery rules
- `preview.html` — self-contained rendered preview of the design system
- `assets/` — extracted brand assets (dog illustration, camera/wearable spot illustrations, paper texture)
- `.github/workflows/deploy-pages.yml` — publishes the preview to GitHub Pages

## Live preview

**https://isd-fyp.github.io/design-guideline/**
